.. _menu-section-about:

About
-----

This menu displays the "About" dialog box.

This dialog box shows the following information:

- Author and email adress
- versions of all external modules used by PySisyphe
- username and user path of the current OS session
- VTK renderer backend, GPU specifications
- CPU specifications, RAM
- Screen (resolution, scaling factor, DPI value)
- Disk (file system, free space)

Left-click **Close** button to exit dialog box.

.. _menu-section-minimize:

Minimize
--------

Minimize the main PySisyphe window (CTRL - shortcut key).

.. _menu-section-maximize:

Maximize
--------

Maximize the main PySisyphe window (CTRL + shortcut key).

.. _menu-section-fullscreen:

Full screen
-----------

This menu displays the main PySisyphe window in full-screen mode (F11 shortcut key).
Press ESC or F11 key to exit full-screen mode.
