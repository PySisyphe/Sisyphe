About

This menu displays the “About” dialog box.

This dialog box shows the following information:

  • Author and email adress

  • versions of all external modules used by PySisyphe

  • username and user path of the current OS session

  • VTK renderer backend, GPU specifications

  • CPU specifications, RAM

  • Screen (resolution, scaling factor, DPI value)

  • Disk (file system, free space)

Left-click Close button to exit dialog box.

Minimize

Minimize the main PySisyphe window (CTRL - shortcut key).

Maximize

Maximize the main PySisyphe window (CTRL + shortcut key).

Full screen

This menu displays the main PySisyphe window in full-screen mode (F11 shortcut key). Press ESC or F11 key to exit full-screen mode.

Show/Hide Toolbar

Toogle Toolbar: visibility of the main PySisyphe window.

Show/Hide Thumbnail

Toogle Thumbnail bar visibility of the main PySisyphe window.

Show/Hide Dock

Toogle dock area visibility of the main PySisyphe window.

Show/Hide Status bar

Toogle status bar visibility of the of the main PySisyphe window.

Next tab

This menu displays the next tab in the central area of the main PySisyphe window (CTRL -> shortcut key).

Previous tab

This menu displays the previous tab in the central area of the main PySisyphe window (CTRL <- shortcut key).

Slice view

This menu displays the Slice view tab in the central area of the main PySisyphe window (F1 shortcut key). There is no effect if no slice view is available in the central area.

Orthogonal view

This menu displays the Orthogonal view tab in the central area of the main PySisyphe window (F2 shortcut key). There is no effect if no orthogonal view is available in the central area.

Synchronized view

This menu displays the Synchronized view tab in the central area of the main PySisyphe window (F3 shortcut key). There is no effect if no synchronized view is available in the central area.

Projection view

This menu displays the Projection view tab in the central area of the main PySisyphe window (F4 shortcut key). There is no effect if no projection view is available in the central area.

Multi-component view

This menu displays the Multi-component view tab in the central area of the main PySisyphe window (F5 shortcut key). There is no effect if no multi-component view is available in the central area.

Database

This menu displays the Database manager tab in the central area of the main PySisyphe window (F6 shortcut key).

File browser

This menu displays the File browser tab in the central area of the main PySisyphe window (F7 shortcut key).

Screenshots

This menu displays the Screenshots manager tab in the central area of the main PySisyphe window (F8 shortcut key).

IPython

This menu displays the IPython console tab in the central area of the main PySisyphe window (F9 shortcut key).
